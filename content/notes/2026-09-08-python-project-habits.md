一个项目往往会被未来的自己重新打开。那时最需要的不是炫技，而是能迅速理解它是做什么的、如何运行、有哪些约束。

## 把启动方式写下来

在 README 中保留最短运行路径、输入输出示例和环境说明。为项目管理独立的依赖，并记录版本。

## 验证关键行为

优先测试真正可能出错的边界与业务规则。让报错说明问题，把重要的假设写在靠近代码的位置。
